วิธีใช้

    
    
      
  1. วางอุปกรณ์: ลากจากแถบซ้ายลงในฉาก (หรือคลิกเพื่อวางอัตโนมัติ) ลากตัวอุปกรณ์เพื่อย้าย กด R หมุน Delete ลบ
    2. 
      
  2. ต่อสาย: คลิกขาทองของอุปกรณ์ แล้วคลิกขาบน ESP32 (หรือเลือกขาในแผงคุณสมบัติ) คลิกสายแล้วกด Delete เพื่อลบ
    3. 
      
  3. ย้ายสาย: คลิกขาที่มีสายต่ออยู่เพื่อถอดปลายสายออก แล้วคลิกขาใหม่เพื่อเสียบ (Esc = ใส่คืนที่เดิม, Delete = ลบสาย) — ถ้าต้องการเดินสายเส้นใหม่จากขาที่มีสายอยู่แล้ว ให้กด Shift ค้างแล้วคลิก
    4. 
      
  4. ไฟเลี้ยง: ขา VCC ต่อ 3V3 หรือ VIN (5V) และ GND ต่อ GND — อุปกรณ์ที่ไม่ได้ต่อไฟจะไม่ทำงาน
    5. 
      
  5. เขียนโค้ด Arduino C++ (setup/loop) แล้วกด ▶ รัน หรือ Ctrl+Enter
    6. 
      
  6. ปรับค่าเซนเซอร์: คลิกเลือกอุปกรณ์ แล้วเลื่อนแถบในแผงคุณสมบัติ ปุ่มกด: คลิกค้างที่ปุ่มสีแดง
    7. 
      
  7. มุมมอง: ลากเมาส์ซ้าย = หมุน, ขวา = เลื่อน, ล้อเมาส์ = ซูม
    8. 
    

    
ไลบรารีที่รองรับ

    
Serial, WiFi (จำลอง), Wire, DHT.h, ESP32Servo.h, Adafruit_SSD1306.h + Adafruit_GFX.h, LiquidCrystal_I2C.h, LEDC/analogWrite, tone, pulseIn, attachInterrupt

    
ข้อจำกัด

    
รองรับภาษา C++ ส่วนที่ใช้บ่อย (ตัวแปร, array, struct, enum, ฟังก์ชัน, String) แต่ยังไม่รองรับ pointer, class, template และ reference ของชนิดพื้นฐาน — โค้ดถูกแปลงเป็น JavaScript และรันในเบราว์เซอร์ ไม่ได้จำลองระดับคำสั่งเครื่องของ ESP32
